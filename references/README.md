# Reference paper

`DeliberativeDistortions.pdf` is the public author manuscript of Luskin, Sood,
Fishkin, and Hahn, *Deliberative Distortions? Homogenization, Polarization, and
Domination in Small Group Discussions*. It was downloaded from
<https://gsood.com/research/papers/DeliberativeDistortions.pdf> and has MD5
`d1e62fbd13340ee1d75791a115f2ab59`.

The manuscript is a reference input for the identification argument. The new
proof does not treat its observed variance decomposition as a latent one.
